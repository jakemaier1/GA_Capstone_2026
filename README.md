# GA_Capstone_2026
General Atomics CPE Capstone Group, working with a YAHBOOM ROSMASTER A1 built around a Jetson Nano. This repository will be used to house ROS2 code

`/scripts`:
- Scripts used to automate the processes of sourcing files, entering docker, and starting up nodes

`/yahboomcar_depth`:
- The entire depth camera ROS2 node. It contains `follow_line.py` and several other scripts that are used in line following with the Angstrong hp60c camera

## How to Push to Repo
1. Make code changes in Docker
2. Add, Commit from Docker in `~/Share` folder
3. Go back to Nano and Push from there
